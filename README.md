911 Cannibal Speedrun Mod
=========================

Author: Kenjy : https://www.speedrun.com/users/KenjyLeBest
Version: 1.0.0

DESCRIPTION
-----------
This mod adds speedrun tools for 911 Cannibal:
- Internal speedrun timer
- Preset system for objects (which you can choose)
- FOV control
- FPS cap + VSync toggle
- Keyboard & gameplay overlay (optional HUD)

This mod is designed for speedrunning.

----------------------------------------------------

INSTALLATION
------------
1. Install MelonLoader for 911 Cannibal (Don't worry, MelonLoader doesn't take up any space on your computer at all). :
   https://melonwiki.xyz/#/README?id=automated-installation

2. Launch the game once to generate folders

3. Go to the game directory:
   911 Cannibal/Mods/

4. Copy:
   SpeedrunMod911.dll

5. Restart the game

----------------------------------------------------

CONTROLS
---------
F3  = Reset timer
F4  = Decrease FOV
F5  = Increase FOV
F8  = Toggle overlay
F9  = Previous preset
F10 = Next preset
F11 = Toggle VSync / FPS cap
